# Docker Yard — интерактивный тренажёр Docker

12 модулей теории, 72 вопроса теста, 26 практических заданий в эмуляторе движка Docker,
написанном на JavaScript: парсер команд, слои с кэшем сборки, сети со встроенным DNS,
тома, compose, оболочка внутри контейнера. Живая схема состояния обновляется после каждой команды.

## Как открыть

* **Локально:** откройте `docker-yard-offline.html` двойным щелчком.
  Это полноценный документ с `<!doctype html>` и `<meta charset="utf-8">` — открывается в любом браузере.
Прогресс хранится в localStorage браузера, отдельно для каждого варианта открытия.
Интернет нужен только для загрузки шрифтов Google Fonts — без него страница работает,
но текст будет системным шрифтом.

## Файлы

| Файл | Назначение |
|---|---|
| `docker-yard-offline.html` | автономная версия для локального открытия |
| `docker-yard.html` | исходник для публикации артефактом (без doctype/head/body — их добавляет публикация) |
| `src/` | части, из которых собираются оба файла |
| `src/build.sh` | пересборка обоих файлов |

## Регрессия

Тесты не требуют браузера — только node:

```sh
cd src
{ tail -n +2 30_engine.js; cat 31_engine2.js 32_engine3.js 33_engine4.js 40_viz.js \
  50_content_a.js 51_content_b.js 52_content_c.js; } > /tmp/core.js
awk '/^\(function shuffleOptions/,/^\}\)\(\);$/' 60_app.js > /tmp/shuffle.js

cat /tmp/core.js /tmp/shuffle.js _sol.js > /tmp/run.js && node /tmp/run.js   # решения всех заданий
cat /tmp/core.js /tmp/shuffle.js _neg.js > /tmp/neg.js && node /tmp/neg.js   # негативный контроль
```

* `_sol.js` прогоняет эталонное решение каждого задания и проверяет, что засчитываются **все** критерии.
* `_neg.js` проверяет обратное: без выполненных команд не должен засчитываться **ни один** критерий,
  плюс контролирует целостность теста (по 4 варианта, корректный индекс ответа, отсутствие дублей,
  равномерность распределения верных ответов).

Добавили задание — допишите его решение в `_sol.js`, иначе тест это заметит.
