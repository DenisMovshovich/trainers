# Гроссбух — интерактивный курс SQL (PostgreSQL)

12 модулей теории, 72 вопроса, 24 задания со 110 автоматическими проверками.
Запросы выполняет встроенный SQL-движок на JavaScript — без сети и без установки PostgreSQL.

## Файлы

| Файл | Что это |
|---|---|
| `grossbuh.html` | исходник артефакта (без `<!doctype>`, `<html>`, `<head>`, `<body>` — их добавляет публикатор) |
| `grossbuh-offline.html` | автономная копия: открывается двойным щелчком из Finder |
| `src/` | исходные части и сценарии сборки и проверки |

## Модули

1. Таблицы и SELECT — реляционная модель, псевдонимы, порядок выполнения запроса
2. WHERE и предикаты — операторы, приоритет AND/OR, диапазоны дат, LIKE
3. NULL — трёхзначная логика, IS NULL, COALESCE, ловушка NOT IN
4. Сортировка и выборка — ORDER BY, положение NULL, LIMIT/OFFSET, DISTINCT
5. Агрегаты и GROUP BY — WHERE против HAVING, FILTER, count(\*) против count(col)
6. Соединения — виды JOIN, ON против WHERE, антисоединение, размножение строк
7. Подзапросы — скалярные, списочные, коррелированные; EXISTS против IN
8. CTE и множества — WITH, рекурсия, UNION / INTERSECT / EXCEPT
9. Оконные функции — PARTITION BY, ранги, топ-N в группе, накопительные итоги
10. Изменение данных — INSERT/UPDATE/DELETE, RETURNING, UPSERT, транзакции
11. Схема и ограничения — типы, PK/FK/UNIQUE/CHECK, поведение при удалении
12. Производительность — индексы, EXPLAIN, sargable-условия, задача N + 1

## Учебная база

Пять связанных таблиц интернет-магазина: `customers` (8), `products` (10), `orders` (12),
`order_items` (20), `employees` (9, с самоссылкой `manager_id` — для самосоединения,
оконных функций и рекурсивного CTE). Схема всегда открыта справа от редактора;
кнопка «Сбросить базу» возвращает исходное состояние.

## Что умеет движок

Разбор и выполнение: SELECT со всеми предложениями, выражения и функции,
трёхзначная логика NULL, INNER/LEFT/RIGHT/FULL/CROSS JOIN и USING, GROUP BY/HAVING,
агрегаты с DISTINCT и FILTER, оконные функции с PARTITION BY и ORDER BY,
подзапросы (скалярные, IN/ANY/ALL, EXISTS, коррелированные, в FROM),
CTE и WITH RECURSIVE, UNION/INTERSECT/EXCEPT [ALL], INSERT/UPDATE/DELETE,
RETURNING, ON CONFLICT DO NOTHING/UPDATE с `excluded`, BEGIN/COMMIT/ROLLBACK,
CREATE/DROP TABLE с PRIMARY KEY, NOT NULL, UNIQUE, REFERENCES, CHECK и DEFAULT,
учебный EXPLAIN.

Сознательно **не** реализованы: `jsonb`, массивы, полнотекстовый поиск, настоящие
индексы, параллельный доступ и уровни изоляции. Синтаксис и семантика — включая
поведение NULL, внешних соединений и правила видимости псевдонимов — воспроизводят
PostgreSQL.

## Сборка и проверка

```sh
cd src
./assemble.sh   # собирает оба HTML
./verify.sh     # полная проверка
```

`verify.sh` последовательно выполняет:

1. **движок** — `runt.sh`: 101 тест на семантику SQL;
2. **эталонные решения** — `check.js`: прогоняет решения ко всем 24 заданиям,
   должно быть 110 / 110;
3. **негативный контроль** — `check.js --neg`: без единого запроса не должна
   пройти ни одна проверка, ожидается 0 / 110;
4. **целостность** — `integrity.js`: 12 модулей, по 6 вопросов с 4 разными
   вариантами и корректным индексом ответа, баланс HTML-тегов во всём тексте,
   текст SVG внутри viewBox;
5. **сборка** обоих файлов;
6. **браузер** — `browser.mjs`: Chromium, 5 сочетаний темы и ширины
   (1500 / 1000 / 760 / 390 px, светлая и тёмная); проверяет отсутствие ошибок
   в консоли, горизонтального перелива на каждом модуле и вкладке, загрузку
   всех трёх гарнитур, живое выполнение запроса, показ ошибки и автоматическое
   засчитывание задания 1a;
7. **раскладка** — `fit.mjs`: правая колонка не уходит под консоль запроса
   на четырёх высотах окна.

## Оформление

Палитра «гроссбух»: тёплая бумага `#EEEBE6` / тёмная `#15120F`, акцент — бычья
кровь `#8C2F39`, синевато-серый `#3F5A6B` для ключей и связей.
Гарнитуры: Spectral (заголовки), Libre Franklin (текст), DM Mono (код и данные).
Тема следует системной, переключается кнопкой и запоминается.
Прогресс хранится в `localStorage` под ключом `grossbuh.v1`.
