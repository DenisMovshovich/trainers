# Мастерская — личный набор интерактивных курсов

Статический сайт для GitHub Pages. Шесть самодостаточных HTML-страниц,
каждая со своим эмулятором внутри. Ни сборки, ни зависимостей, ни сервера.

## Что внутри

| Путь | Инструмент | Источник |
|---|---|---|
| `docker/` | Docker Yard | `../docker-trainer/` |
| `rest/` | Проволока REST | `../rest-wire/` |
| `bash/` | Оболочка на ладони | `../bash-palm/` |
| `sql/` | Гроссбух (SQL) | `../sql-grossbuh/` |
| `kafka/` | Диспетчерская (Kafka) | `../kafka-dispatch/` |
| `testing/` | Протокол проверки | `../qa-protocol/` |

Сюда не входят «Анатомия Portal» и «Сборочный лист .NET»: они устроены иначе —
это разборы, а не курсы с прогрессом, и на титульной странице сайта им не место.
Открываются напрямую из своих папок.

## Обновление

После правки любого инструмента:

```sh
./sync.sh          # переносит свежие автономные копии в папки сайта
git add -A && git commit -m "обновление" && git push
```

## Первая публикация

```sh
git init -b main
git add -A
git commit -m "мастерская: шесть курсов"
gh repo create qa-lab --private --source=. --push
gh api -X POST repos/:owner/qa-lab/pages -f build_type=workflow \
  -f 'source[branch]=main' -f 'source[path]=/'
```

Либо через веб-интерфейс: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

Адрес будет вида `https://<логин>.github.io/qa-lab/`.
Первая сборка занимает пару минут.

## Файл `.nojekyll`

Пустой файл в корне отключает обработку Jekyll. Без него GitHub игнорирует
папки и файлы, начинающиеся с подчёркивания, и может сломать раздачу.

## Про приватность

Pages на бесплатном тарифе публичен: ссылку может открыть любой, кто её знает.
Поисковую индексацию гасит `<meta name="robots" content="noindex, nofollow">`
на титульной странице — но это просьба к поисковикам, а не защита.
Если нужна настоящая приватность, вариантов два: платный GitHub Enterprise Cloud
с приватными Pages либо локальная раздача — `python3 -m http.server 8000`
из этой папки и `http://localhost:8000` в браузере.
