# C# — интерактивный курс языка

12 разделов теории, 74 вопроса, 26 заданий со 104 автоматическими проверками
и 26 разборов вопросов с собеседований. Код выполняет встроенный интерпретатор C#
на JavaScript — без сети, без .NET SDK и без компиляции.

## Файлы

| Файл | Что это |
|---|---|
| `csharp.html` | исходник артефакта (без `<!doctype>`, `<html>`, `<head>`, `<body>` — их добавляет публикатор) |
| `csharp-offline.html` | автономная копия: открывается двойным щелчком из Finder |
| `src/` | исходные части и сценарии сборки и проверки |

## Разделы

1. Значимые и ссылочные — копирование при присваивании, ловушка ссылки внутри структуры
2. Строки — неизменяемость, `==` против `Equals`, `IsNullOrWhiteSpace`, `StringBuilder`
3. Коллекции — `List`, массив, `Dictionary`, `HashSet`; исключения и их безопасные двойники
4. LINQ — отложенное выполнение, повторный обход, `First` против `Single`, группировка
5. Классы — поле против свойства, `value` в сеттере, конструктор против инициализатора, статика
6. Наследование — `virtual`/`abstract`/`override`, `base`, `override` против `new`, `sealed`
7. Интерфейсы — контракт, внедрение зависимости, заглушка своими руками, mock/stub/fake
8. null — источники, `?.` и `??`, `int?`, `ArgumentNullException` и `nameof`
9. Исключения — порядок блоков, `finally` после `return`, `throw` против `throw ex`
10. async/await — порядок выполнения, `WhenAll`, тупик от `.Result`, `async void`
11. using — `IDisposable`, порядок освобождения, драйвер браузера в тестах
12. Тонкости — целочисленное деление, `0.1 + 0.2`, `GetHashCode`, замыкание переменной цикла, упаковка

## Что умеет интерпретатор

Операторы верхнего уровня без `Main`. Классы, структуры, интерфейсы, перечисления;
поля, авто-свойства и свойства с телом, выражения-свойства, конструкторы с `: base(...)`
и `: this(...)`, `virtual`/`abstract`/`override`/`new`, статические члены. Управляющие
конструкции, `try/catch/finally`, `using`, локальные функции и лямбды с замыканиями.
`ref` и `out` с возвратом значений. `List<T>`, массивы, `Dictionary<K,V>`, `StringBuilder`,
инициализаторы объектов и коллекций. LINQ с настоящей отложенностью. Собственные типы
исключений с сообщением через `base`. `async`/`await`, `Task`, `Task.Delay`, `Task.WhenAll`
на виртуальном планировщике: задержки не занимают реального времени.

Сознательно **не** реализованы: пространства имён, `partial`, атрибуты, события,
обобщённые пользовательские типы, рефлексия, настоящие потоки, файлы и сеть.

Семантику, на которой ловят, движок воспроизводит точно и **падает там, где падает C#**:
копирование значимых типов, неизменяемость строк, отложенность LINQ, `InvalidOperationException`
при изменении коллекции во время `foreach`, порядок `finally` и `Dispose`, захват переменной
цикла (`for` даёт `3 3 3`, `foreach` — `0 1 2`), различие `override` и `new` — последнее
потребовало хранить объявленный тип переменной, потому что скрытый метод виден только
через переменную своего типа.

## Сборка и проверка

```sh
cd src
./assemble.sh   # собирает оба HTML
./verify.sh     # полная проверка
```

`verify.sh` последовательно выполняет:

1. **движок** — `runt.sh`: 104 теста на семантику C#;
2. **эталонные решения** — `check.js`: прогоняет решения ко всем 26 заданиям
   через интерпретатор, должно быть 104 / 104;
3. **негативный контроль** — `check.js --neg`: без единого запуска не должна
   пройти ни одна проверка, ожидается 0 / 104;
4. **целостность** — `integrity.js`: 12 разделов, вопросы с 4 разными вариантами
   и корректным индексом ответа, баланс HTML-тегов во всём тексте, отсутствие
   посторонних тегов внутри примеров кода, а также прогон всех 30 примеров
   из нижней панели через движок — ошибка **разбора** недопустима, ошибка
   выполнения у пяти примеров намеренная и есть предмет урока;
5. **сборка** обоих файлов;
6. **браузер** — `browser.mjs`: Chromium, 5 сочетаний темы и ширины
   (1540 / 1120 / 820 / 390 px, светлая и тёмная); проверяет отсутствие ошибок
   в консоли и горизонтального перелива на каждом разделе и вкладке, отсутствие
   утечки скрытых панелей, загрузку всех трёх гарнитур, живое выполнение кода,
   показ ошибки, порядок вывода асинхронного примера и автоматическое
   засчитывание задания 1a;
7. **раскладка** — `fit.mjs`: правая колонка не уходит под редактор на шести
   высотах окна.

## Оформление

Палитра «стенд»: холодный графит `#1B1D21` / светлая `#F2F3F5`, акцент —
фиолетовый `#6F42C1` (цвет C#), бирюзовый для значений.
Гарнитуры: Space Grotesk (заголовки), Inter (текст), JetBrains Mono (код).
Редактор слева, вывод справа, справочник по возможностям движка в правой колонке.
Тема следует системной, переключается кнопкой и запоминается.
Прогресс хранится в `localStorage` под ключом `csharp.v1`.
