Git — интерактивный курс контроля версий: 12 разделов теории, 72 вопроса, 26 заданий со 112 автоматическими проверками и 21 разбор вопросов с собеседований. Команды выполняет встроенный git на JavaScript: адресуемое содержимым хранилище объектов, индекс, ветки и метки, трёхстороннее слияние с настоящими конфликтами, перебазирование с интерактивным планом, reflog, stash, двоичный поиск и отдельный репозиторий на роли сервера.

Реализация учебная и намеренно упрощена: нет подмодулей, worktree, хуков, подписей, разреженной выгрузки и упаковки объектов, а хеш — не SHA-1, хотя ведёт себя так же. Поведение воспроизводит настоящий git там, где это важно: индекс отдельно от рабочей копии, игнорирование не действует на отслеживаемые файлы, перемотка против коммита слияния, смена хешей при перебазировании, отказ push при расхождении и проверка --force-with-lease. Прогресс хранится в браузере.
