# Анатомия Portal — разбор проекта автотестов

Интерактивный разбор учебного проекта UI-автотестов на C# (Playwright + NUnit):
каждый файл, класс, свойство и метод с объяснением, зачем он нужен.

## Как открыть

`portal-anatomy-offline.html` — двойной щелчок из файлового менеджера.
Ни сервера, ни сборки не требуется.

## Что внутри

| Раздел | О чём |
|---|---|
| Файл | построчный разбор: 52 файла проекта, роль каждого |
| Карта проекта | как связаны страницы, тесты, конфигурация и утилиты |
| Наследование | иерархия классов: базовые страницы, базовые фикстуры |
| Области видимости | public/private/protected и почему именно так |
| Page Object | локаторы, действия, где границы ответственности |

Разбор построен на модели, извлечённой из исходников скриптом `src/extract.py`:
имена типов, членов, модификаторы, атрибуты и связи между файлами.

## Данные обезличены

Проект в разборе — **вымышленный** `Acme.WebAutomation.Portal`. Структура,
имена файлов и архитектурные решения взяты из реального рабочего проекта,
но всё, что указывало на конкретную компанию, заменено: пространства имён,
адреса стендов (`*.example.com`), идентификаторы задач (`TC-####`).

Материал имеет смысл как **образец архитектуры** набора UI-автотестов,
а не как документация к чьему-то конкретному коду.

## Сборка

```sh
cd src/build && ./assemble.sh
```

Собирает обе версии: `portal-anatomy.html` (фрагмент без обёртки) и
`portal-anatomy-offline.html` (полноценный документ). Модель берётся
из `src/model.js`.

Обновить модель из своего репозитория:

```sh
REPO_PATH=/путь/к/проекту python3 src/extract.py
```

## Проверка

```sh
npm i -D playwright-core && npx playwright install chromium
node src/_smoke.mjs      # загрузка без ошибок
node src/_interact.mjs   # переключение вкладок и разделов
node src/_svg.mjs        # подписи схем внутри viewBox
node src/_mobile.mjs     # раскладка на узком экране
```

Пути внутри скриптов не зашиты: браузер берётся из `node_modules`,
переопределяется переменными `PLAYWRIGHT_CORE` и `CHROMIUM_PATH`.
