# Оболочка на ладони

Интерактивный тренажёр по bash. Внутри — **настоящий интерпретатор оболочки** на JavaScript
поверх виртуальной файловой системы: разбор кавычек, все раскрытия в правильном порядке,
конвейеры, перенаправления, условия, циклы, функции и скрипты.

* **Локально:** `bash-palm-offline.html` — открывается двойным щелчком.

## Терминал

Закреплён внизу и доступен **на любой вкладке** — можно пробовать прямо во время чтения теории.
Справа — живое дерево виртуальной файловой системы; исполняемые файлы помечены звёздочкой.

* **Enter** — выполнить, **Shift+Enter** — новая строка (так пишутся скрипты и heredoc)
* **↑ ↓** — история, `clear` — очистить ленту, `reset` — начать задание заново

## Что умеет интерпретатор

Разбор: кавычки трёх видов с посимвольной маской, раскрытия в порядке
brace → тильда → параметры/`$(…)`/`$((…))` → разбиение слов → шаблоны → снятие кавычек.
Подстановки `${X:-…}` `${#X}` `${X#…}` `${X%…}` `${X/…/…}`. Конвейеры (каждое звено —
подоболочка), перенаправления включая heredoc и here-string, `&&`/`||`, `if`/`elif`/`else`,
`for`, `while`/`until`, `case`, функции, `local`, `return`, `source`, `set -euo pipefail`,
запуск скриптов по пути с проверкой бита исполнения.

Утилиты: ls cat head tail wc grep sort uniq cut tr sed awk find xargs tee touch mkdir rmdir
rm cp mv chmod stat file basename dirname seq rev nl tree whoami id hostname env which date man.

Поведение выверено по настоящему bash, включая мелочи: `ls` печатает по имени на строку,
когда вывод не в терминал; `405`-подобных упрощений нет — `[ = x ]` даёт синтаксическую ошибку,
пустая переменная без кавычек исчезает, `"$@"` разворачивается по одному слову на аргумент.

## Проверка

```sh
cd src && ./verify.sh
```

Четыре набора, все без браузера:

* **90 тестов движка** — основы: кавычки, раскрытия, перенаправления, фильтры, циклы, скрипты.
* **36 тестов на ловушки** — heredoc, `"$@"`, исчезающие пустые слова, pipefail, подоболочки.
* **Решения всех 23 заданий** — прогоняются целиком, засчитываются все 125 критериев.
* **Негативный контроль** — без единой команды не должен засчитываться ни один критерий;
  плюс целостность теста и баланс HTML-тегов в теории.
