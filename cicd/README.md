# CI/CD — интерактивный курс непрерывной интеграции

12 разделов теории, 72 вопроса, 23 задания со 109 автоматическими проверками
и 12 разборов вопросов с собеседований. Конвейер выполняет встроенный движок
на JavaScript — без сети, без раннеров и без ожидания.

## Файлы

| Файл | Что это |
|---|---|
| `cicd.html` | исходник артефакта (без `<!doctype>`, `<html>`, `<head>`, `<body>` — их добавляет публикатор) |
| `cicd-offline.html` | автономная копия: открывается двойным щелчком из Finder |
| `src/` | исходные части и сценарии сборки и проверки |

## Разделы

1. Конвейер — зачем нужен, время конвейера против машинного, что автоматизируют первым
2. Описание — `on`, `jobs`, `steps`, `run` против `uses`, чистая машина, ловушка с `on` в YAML
3. Задачи — зависимости, параллельность, что между задачами **не** переносится
4. Контексты — `github`, `env`, `secrets`, `matrix`, `needs`, `steps`; `$GITHUB_OUTPUT` и `$GITHUB_ENV`
5. Матрица — размножение задачи, шардирование тестов, `fail-fast`, `include` и `exclude`
6. Кеш — ключ на `hashFiles`, запасные ключи, что кешируют и что нет
7. Артефакты — отчёты и трассировки, `if: always()`, передача между задачами
8. Условия — `success`, `failure`, `always`, `continue-on-error`, условия на уровне задачи
9. Секреты — маскирование, форки, подстановка данных события в команду, права
10. Тесты — нестабильность, перезапуски как временная мера, разделение по скорости
11. Скорость — где уходит время, три рычага и что каждый даёт, отмена устаревших запусков
12. Проектирование — стадии, гейты, откат, чек-лист зрелого конвейера

## Что умеет движок

Разбор YAML и вычисление выражений `${{ }}` с контекстами и функциями (`contains`,
`startsWith`, `format`, `hashFiles`, `success`, `failure`, `always`). Граф задач
с `needs`, параллельным выполнением и подсчётом двух времён — конвейера и машинного.
Матрицы с `include`, `exclude`, `fail-fast` и отменой отставших. Условия на уровне
шага и задачи. Кеш с точными и запасными ключами, переживающий запуски. Артефакты
с выгрузкой, загрузкой и переносом содержимого между задачами. Маскирование секретов
и их отсутствие для запусков из форка. Набор из 70 тестов с двумя нестабильными,
фильтрами по группам, шардированием и перезапусками. Встроенная проверка описания
(`ci lint`), которая ловит отсутствие выгрузки кода, ключ кеша без `hashFiles`
и артефакт без условия.

Команды: `ci run` (в том числе `--event`), `jobs`, `logs`, `graph`, `artifacts`,
`cache`, `history`, `lint`, `tests`, `secrets`; плюс `ls` и `cat` для файлов проекта.

Сознательно **не** реализованы: собственные действия, повторно используемые конвейеры,
окружения с ручным подтверждением, сервисные контейнеры и настоящая сеть; список
известных инструментов и действий фиксирован.

Поведение воспроизводит настоящую систему там, где на этом учатся: задачи не делят
файловую систему, шаги после падения пропускаются, собственный `if` отменяет
умолчание, ключ кеша без отпечатка зависимостей не обновляется, артефакт без
`always()` теряется именно при падении, а запуску из форка секреты не выдаются.

## Сборка и проверка

```sh
cd src
./assemble.sh   # собирает оба HTML
./verify.sh     # полная проверка
```

`verify.sh` последовательно выполняет:

1. **движок** — `runt.sh`: 44 теста на поведение конвейера;
2. **эталонные решения** — `check.js`: решения ко всем 23 заданиям, должно быть 109 / 109;
3. **негативный контроль** — `check.js --neg`: на нетронутом сценарии не должна
   пройти ни одна проверка, ожидается 0 / 109;
4. **целостность** — `integrity.js`: разделы и вопросы, баланс HTML-тегов, отсутствие
   посторонних тегов в примерах, построение всех 23 сценариев с разбором вложенных
   в них файлов конвейера и прогон всех примеров из нижней панели;
5. **сборка** обоих файлов;
6. **браузер** — `browser.mjs`: Chromium, 5 сочетаний темы и ширины
   (1540 / 1120 / 820 / 390 px, светлая и тёмная). Кроме ошибок консоли и перелива
   проверяет живые сценарии: запуск конвейера, починку падения правкой описания
   в редакторе, разворачивание матрицы в три шарда и сохранение артефакта при
   падении — и что задания 1b, 5a и 7a после этого засчитываются;
7. **раскладка** — `fit.mjs`: правая колонка не уходит под терминал на шести
   высотах окна.

## Оформление

Палитра «стапель»: тёмный графит `#111318` / тёплая светлая `#F4F4F1`, акцент —
бирюзовый `#0F766E`, зелёный и красный для статусов задач.
Гарнитуры: Archivo (заголовки), Rubik (текст), Fira Code (терминал).
Слева терминал, справа последний запуск: задачи со статусами, полосы времени
и сводка по двум временам, артефактам и кешу.
Нижняя панель переключается между терминалом и редактором описания конвейера.
Тема следует системной, переключается кнопкой и запоминается.
Прогресс хранится в `localStorage` под ключом `ci.v1`.
